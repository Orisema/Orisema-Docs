# Orisema Infrastructure

> Uma ideia nasce. Muitas mãos a fazem crescer.

O **Orisema Infrastructure** é uma CLI comunitária em Go para implantação declarativa, inspeção, diagnóstico e operações conservadoras com contêineres.

> **Experimental:** não é recomendado para produção. O runtime oficialmente suportado é **Podman em Linux**. Docker, Windows e macOS ainda não são suportados.
