# Orisema Infrastructure

> An idea is born. Many hands help it grow.

**Orisema Infrastructure** is a community-built Go CLI for declarative deployment, inspection, diagnostics and conservative container operations.

> **Experimental:** not recommended for production. **Podman on Linux** is the only officially supported runtime. Docker, Windows and macOS are not supported yet.
