# Orisema Infrastructure

> Nace una idea. Muchas manos la hacen crecer.

**Orisema Infrastructure** es una CLI comunitaria en Go para despliegue declarativo, inspección, diagnóstico y operaciones conservadoras con contenedores.

> **Experimental:** no se recomienda para producción. **Podman en Linux** es el único runtime oficialmente compatible. Docker, Windows y macOS todavía no son compatibles.
